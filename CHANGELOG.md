# Changelog

Все заметные изменения в проекте документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.3.1] — 2026-08-26

### Изменено
- Совместимость подтверждена до WordPress 7.1 (проверено в wp-env). Без изменений кода; релиз нужен, чтобы каталог WP.org переимпортировал метаданные — правка readme в trunk и теге (r3666038) поле `tested` не обновила.

## [1.3.0] — 2026-05-25

### Изменено
- Author URI обновлён на `https://delosvod.ru/`.
- Совместимость подтверждена до WordPress 7.0 (Tested up to).

## [1.2.0] — 2026-04-29

### Изменено
- Ребрендинг плагина: «No Crumbs» → «NoCrumbs Cookie Notice».
- Slug и Text Domain обновлены на `nocrumbs-cookie-notice`.
- Переименованы файлы ассетов: `no-crumbs.css` → `nocrumbs-cookie-notice.css`, `no-crumbs.js` → `nocrumbs-cookie-notice.js`.
- Переименован POT-файл: `no-crumbs.pot` → `nocrumbs-cookie-notice.pot`.
- Обновлены хэндлы `wp_enqueue_style` / `wp_enqueue_script` для соответствия новому slug.

## [1.1.0] — 2026-04-21

### Добавлено
- Брендинговые ссылки действий («Техблог СТОДУМ» и «Больше инструментов») в строке плагина на странице «Плагины».

## [1.0.0] — 2026-04-16

### Добавлено
- Баннер уведомления о cookie в формате «Card Style» (нижний левый угол).
- Поддержка 152-ФЗ из коробки с готовыми формулировками на русском языке.
- Автоматическая ссылка на страницу «Политика конфиденциальности» из настроек WordPress.
- Zero Bloat: Vanilla JS + CSS3, около 5 Кб суммарно. Без jQuery, без внешних шрифтов.
- Полная совместимость с кэшированием (клиентская проверка cookie).
- Плавная CSS-анимация появления и исчезновения баннера.
- Адаптивная вёрстка (мобильные устройства).
- Интернационализация (i18n) с POT-файлом.
- Файл `uninstall.php` для корректного удаления.
- Файл `readme.txt` для WordPress.org.
